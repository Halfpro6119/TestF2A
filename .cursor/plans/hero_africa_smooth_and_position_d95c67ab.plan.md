# Hero: Smooth Africa and Reposition UK/Africa

## Current behavior

- **Hero**: [components/hero-illustration.tsx](c:\Users\Riley\OneDrive\Documents\F2A Website\TestF2A\components\hero-illustration.tsx) draws one SVG using path strings from [lib/hero-map-paths.ts](c:\Users\Riley\OneDrive\Documents\F2A Website\TestF2A\lib\hero-map-paths.ts).
- **Paths**: Generated by [scripts/generate-hero-paths.js](c:\Users\Riley\OneDrive\Documents\F2A Website\TestF2A\scripts\generate-hero-paths.js), which uses world-atlas countries-110m, merges African countries into a **MultiPolygon** (one ring per country), then outputs a single path `d` string.
- **Why Africa has “borderlines”**: The path contains many subpaths (each `M...Z` is one country). The shared edges between countries are still drawn, so internal boundaries are visible. To get a smooth continent you need a **single outline** (outer boundary only).
- **Positioning**: UK is fitted to `[[340,100],[560,420]]`, Africa to `[[680,80],[1080,460]]`. The reference has UK in the upper-right area and Africa to the right and slightly below; extents can be tuned to match.

## 1. Smooth Africa (no internal borderlines)

**Approach: Dissolve African countries into one polygon in the generator.**

- In the script, after collecting African country features, **union** them so shared boundaries disappear and only the continent outline remains. Use **Turf.js** `union` (or sequential union of polygons) in the Node script only; no runtime dependency in the app.
- **Steps**:
  - Add **`@turf/union`** (or `@turf/turf`) as a **devDependency**.
  - In `generate-hero-paths.js`: instead of `mergeGeometries()` (which keeps a MultiPolygon with one polygon per country), convert African features to a FeatureCollection of Polygons (expand MultiPolygons into separate Polygon features), then call Turf’s `union()` on that collection. If the result is MultiPolygon (e.g. mainland + Madagascar), that’s acceptable — you’ll have a few outer rings and no country-internal borders.
  - Keep using `geoPath().projection(projAfrica)` on the unioned feature to produce a single path string (possibly with multiple subpaths only for disconnected landmasses like Madagascar).
  - Re-run the script and replace the contents of `lib/hero-map-paths.ts` with the new `UK_PATH` and `AFRICA_PATH`.
- **Optional alternative**: Use a pre-made Africa continent GeoJSON (e.g. Natural Earth land filtered to Africa, or a single-polygon Africa from a public repo), load it in the script, and project that single feature. This avoids Turf but requires finding/maintaining that file.

## 2. Position UK and Africa like the reference

- **Reference**: UK in the upper-right area; Africa to the right and slightly below the UK (geographically consistent).
- **Implementation**: Adjust the **fit extents** in `scripts/generate-hero-paths.js` so that in the hero viewBox (0 0 1200 540):
  - **UK**: Positioned upper-right (e.g. x roughly 400–620, y 90–380) so it sits “upper-right-middle” as in the reference.
  - **Africa**: Positioned to the right and slightly lower (e.g. x 700–1100, y 140–460) so it’s clearly to the right of the UK and a bit below.
- Tweak the arrays `viewBoxUK` and `viewBoxAfrica` (e.g. change from `[[340,100],[560,420]]` and `[[680,80],[1080,460]]` to values that match the reference layout), then re-run the script.
- **Optional**: If the path curve or plane animation endpoints (e.g. `M 420 320 Q ... 950 280` in the hero) no longer align nicely with the new shapes, adjust the flight path and `animateMotion` path in [components/hero-illustration.tsx](c:\Users\Riley\OneDrive\Documents\F2A Website\TestF2A\components\hero-illustration.tsx) so the dashed line runs from the southeastern UK toward the eastern side of Africa. Footprint icon positions (e.g. `translate(465, 260)` for UK, `translate(870, 290)` for Africa) can be updated once the new path positions are final.

## 4. Implementation notes

- **Turf union**: Turf’s `union` accepts a FeatureCollection of (Multi)Polygon features. For many polygons, repeated pairwise union can be slow; use `@turf/union` with a single FeatureCollection of all African polygons (Turf will merge them). If the collection is too large, consider merging in chunks or using a pre-made continent outline instead.
- **Stroke**: Keep `stroke="#8bb87a"` and `strokeWidth="2"` on the Africa path so the **outer** coastline is still visible; only internal borders disappear after union.
- **No change** to hero structure (one SVG, same gradients, ripples, logo, foreground wave). Only the path data and possibly path/plane/footprint coordinates change.
